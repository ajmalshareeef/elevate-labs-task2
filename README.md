# Task 2: Data Visualization and Storytelling

## Overview

This project was completed as part of a Data Analyst Internship. The objective was to create a Power BI dashboard that presents sales data in a clear and meaningful way. The dashboard focuses on highlighting key business metrics and trends to support better decision-making.

## Tools Used

- Microsoft Power BI
- Sample Superstore Dataset (CSV)

## Dataset

The project uses the Sample Superstore dataset, which contains information about:

- Orders
- Sales
- Profit
- Quantity
- Customers
- Products
- Categories
- Regions
- States
- Shipping Details

## Dashboard Features

The dashboard includes the following visualizations:

- KPI Cards showing Total Sales, Total Profit, Total Orders, and Total Quantity Sold
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Sales by Customer Segment
- Top 10 Products by Sales
- Sales Distribution by State

Interactive slicers were added for:

- Region
- Category
- Segment
- Ship Mode

These filters allow users to explore the data from different perspectives.

## Business Insights

The dashboard helps answer questions such as:

- Which product category generates the highest sales?
- Which region is the most profitable?
- How do sales change over time?
- Which customer segment contributes the most revenue?
- Which products perform the best?
- How are sales distributed across different states?
